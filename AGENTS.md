# Workspace Guidelines & Rules

## SEO, Data Freshness & Anti-Deception Policy
- **No Fake/Auto-Updated Dates**: Never override original post/entry dates with current system date (`NOW()`) on legacy or static content.
- **Strict Content Grid Categorization**:
  - **Live Latest Alerts**: Filter strictly for current-year active notifications (`createdAt >= CurrentYear`).
  - **Citizen Utility Services / Tools**: Move multi-year static topics (Aadhar, PAN, License, Voter ID) to a dedicated evergreen section.
- **Title-Content Integrity**: Card titles, badges, and year tags must match post contents 100% to ensure high CTR and zero bounce rate.
